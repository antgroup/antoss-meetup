# 蚂蚁开源技术沙龙 × CLSF（China Linux System Forum）：Agentic 时代的系统技术

2026 年 6 月 6 日，由蚂蚁开源联合 CLSF（China Linux System Forum）共同在成都举办了“Agentic 时代的系统技术”主题技术沙龙，聚焦 「Agent Sandbox：为 AI Agent 构建安全、隔离、高效的执行环境」，「System for Agentic AI：面向智能体负载的操作系统与系统软件创新」两大核心方向，共同带来了一场关于 Agentic 时代的系统技术的技术交流和思想碰撞。
此仓库收录了本次 Meetup 中所有分享的演讲材料，方便大家回顾和学习。欢迎加入我们的社区，一起交流与成长，更多丰富的开源活动欢迎关注蚂蚁开源！
